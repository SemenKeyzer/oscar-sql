```bash

qmake6 ../oscar-sql/oscar/oscar.pro CONFIG+=test && make -j8
```


  оригинал 1,84 / 1,64, адаптированный 1,96 / 1,83; отец на Prisma 1,87 / 1,85. Индекс у отца и
  Семена почти одинаков, хотя ограничение потока разное (6–18 % против 13–42 %): индекс в основном
  «нет паузы» и «изменчивость амплитуды», ограничение потока он различает слабо.
- Ночь на 07.10 на Prisma — Семен (обмен аппаратами), для ещё одной проверки.
