- Ветка: `master` форка `SemenKeyzer/oscar-sql`
- Статус: дизайн согласован с владельцем в чате (охват и состав, механизм, тесты); ждёт просмотра
  спецификации
- Основа: этап 1 (`docs/superpowers/specs/2026-10-07-hover-help-design.md`) — словарь
  `Glossary`, `HelpTips`, `HelpPanel`, галочка «Вид → Пояснения при наведении»

## 1. Цель

Этап 1 объяснил цифры и термины. Этап 2 объясняет **элементы управления**: что делает пункт меню,
кнопка, галочка или поле, что обычно выбрать и чем действие опасно. Та же галочка отключает всё.

Решения владельца: охват — **всё сразу, ровно** (меню, кнопки вкладок, настройки, импорт и
оксиметрия); пояснение — **что делает + совет + «осторожно»**; устройство — **подход A**: вторая
таблица словаря, привязка по имени элемента (`objectName`).

## 2. Охват (≈300 элементов)

- **Главное меню** (`mainwindow.ui`, ~76 пунктов): все пункты с текстом.
- **Кнопки и переключатели вкладок** «День» (`daily.ui`), «Сводка» (`overview.ui`), «Статистика»,
  стартовая страница (`welcome.ui`): календарь, переход по дням, выбор периода, профили графиков,
  поиск событий.
- **«Настройки»** (`preferencesdialog.ui`, ~125 элементов): все вкладки — поля, галочки, списки,
  группы, кнопки.
- **Импорт с карты:** его пункты меню и кнопка импорта стартовой страницы (уже в охвате меню и
  `welcome.ui`); статьи этих элементов объясняют сам импорт — что выбрать, что будет с уже
  загруженными ночами.
- **Оксиметрия:** мастер `oximeterimport.ui`, страница Bluetooth (`bluetoothoximeterpage`, Contec),
  окно оксиметрии (`oximetry.ui`).

**Не входят** (возможный этап 3): «О программе», обновления, SQL-редактор, редактор отчётов,
резервная копия / восстановление / «поделиться», создание и выбор профиля, тексты сообщений об
ошибках.

## 3. Состав пояснения

| Поле | Что | Пример |
|---|---|---|
| `term` | название элемента, как на экране | «Порог большой утечки» |
| `place` | где он находится | «Настройки → CPAP» |
| `summary` | что делает, 1–2 фразы простым языком (≤ 300 знаков) | |
| `advice` | совет; пусто — нет | «Обычно оставьте как есть. Для Prisma 20A…» |
| `caution` | только у действий, которые удаляют данные, пересчитывают анализ или долго работают | «Удаляет все данные аппарата из профиля; вернуть можно только повторным импортом с карты» |
| `seeAlso` | ключи статей этапа 1 или 2 | `leak` |

Тексты — на английском в таблице (`QT_TRANSLATE_NOOP("Glossary", …)`, написанный буквально — lupdate
не раскрывает макросы) и на русском в `Russkiy.ru.ts`.

## 4. Механизм

### 4.1 Словарь
- `GlossaryEntry` получает поля `QString place`, `QString advice`, `QString caution`.
- Новая таблица `oscar/uiglossary.cpp` (ключи `ui.<окно>.<objectName>`: `ui.menu.*`, `ui.prefs.*`,
  `ui.daily.*`, `ui.overview.*`, `ui.stats.*`, `ui.welcome.*`, `ui.oximport.*`, `ui.ble.*`,
  `ui.oximetry.*`). `Glossary::find/all/search/tooltip/panel` работают по обеим таблицам.
- `Glossary::tooltip` для записи интерфейса: **название** — что делает; *совет*; «⚠ осторожно…»
  красным. `Glossary::panel`: название, «где», «Что делает», «Совет», «Осторожно», «См. также».
- Поиск панели находит и записи интерфейса; в списке результатов у них виден `place`
  («Порог большой утечки — Настройки → CPAP»).

### 4.2 Подключение к окнам
- `HelpTips::attachAll(QWidget *root, const QString &window)` — обходит всех потомков `root`; если
  есть запись `ui.<window>.<objectName>`, ставит ключ (`attach`). Для `QLabel` с `buddy()` берёт
  ключ поля-партнёра; если у подписи нет партнёра, но есть своя запись — свою. `QGroupBox` получает
  ключ, если есть запись (обход родителей уже показывает его на пустом месте группы).
- Вызывается один раз при создании окна: `MainWindow` (вкладки «День», «Сводка», «Статистика»,
  стартовая страница), `PreferencesDialog`, `OximeterImport`, страница Bluetooth, окно оксиметрии.
- Элементам, создаваемым в коде без `objectName` (страница Bluetooth, кнопки «Дня»), имя задаётся.

### 4.3 Подсказка
Как в этапе 1: при включённой галочке фильтр показывает подсказку словаря вместо подсказки Qt; при
выключенной — старая подсказка Qt. Ничего в `.ui` не переписывается.

### 4.4 Меню
- `QMenu::hovered(QAction*)` каждого меню главного окна → `HelpTips::hover("ui.menu." +
  action->objectName())`, если запись есть. На macOS работает и в системной строке меню (подсказку
  при наведении там рисует сама система — её не меняем).
- Фильтр: если событие `ToolTip` пришло в `QMenu` (Windows / Linux), ключ берётся у
  `menu->activeAction()`.

### 4.5 Полоса пояснения в модальных окнах
`HelpStrip` (`oscar/helpstrip.{h,cpp}`) — `QTextBrowser` высотой 3–4 строки внизу окна
«Настройки» и мастера импорта оксиметрии. Показывает полную статью наведённого элемента (по
`HelpTips::hovered`, только если элемент принадлежит этому окну), с прокруткой; при уводе мыши не
стирается; без статьи — «Наведите мышь на настройку, чтобы увидеть пояснение». При выключенной
галочке полоса скрыта. Панель справки главного окна при этом тоже следует за наведением, как сейчас.

## 5. Тесты и проверка
- **Словарь интерфейса:** у каждой записи `ui.*` есть term, place, summary; summary ≤ 300 знаков;
  ключи уникальны в обеих таблицах вместе; ссылки «См. также» существуют; `caution` есть ровно у
  явного списка опасных действий (очистка данных, пересчёт, смена папки данных, повторный импорт,
  сброс настроек) и ни у чего больше.
- **Полнота:** тест создаёт `PreferencesDialog`, `OximeterImport` (с Bluetooth-страницей в сборке
  с BT), окно оксиметрии, вкладки «День» / «Сводка» и меню главного окна, вызывает `attachAll`;
  каждый интерактивный элемент (`QAbstractButton`, `QComboBox`, `QAbstractSpinBox`, `QLineEdit`,
  `QSlider`, `QDateTimeEdit`, `QAction` меню с текстом, `QGroupBox` с флажком) получает ключ или
  стоит в явном списке исключений (OK / Отмена / Применить, разделители, служебные). Новая
  настройка upstream без пояснения роняет тест.
- **Механизм:** `attachAll` ставит ключ по имени; подпись берёт ключ партнёра; `QMenu::hovered`
  шлёт `hovered`; `ToolTip` в `QMenu` даёт подсказку активного пункта; подсказка интерфейса
  содержит совет и «осторожно»; при выключенной галочке — подсказка Qt, полоса скрыта.
- **Полоса:** показывает статью наведённого элемента своего окна, не очищается при уводе, игнорирует
  элементы других окон.
- **Перевод:** все новые строки на русском, `validate_ts.py` = 0.
- **В приложении** (только `--datadir …/OSCAR20_Data_dev`, фоновые `app_*`, экран не захватывается):
  открыть «Настройки» и импорт оксиметрии, убедиться, что полоса на месте; наведение мышью на
  несколько галочек и пунктов меню проверяет владелец.
