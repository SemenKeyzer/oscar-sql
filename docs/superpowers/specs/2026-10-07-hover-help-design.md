- Дата: 2026-10-07
- Ветка: `master` форка `SemenKeyzer/oscar-sql`
- Статус: дизайн согласован с владельцем в чате (по частям: словарь и механизм, охват, панель
  и проверка); ждёт просмотра спецификации
- Источник: идея владельца — «навёлся на строку или термин, мышка показывает расшифровку и короткое
  пояснение, что это и как интерпретировать; для всего интерфейса; легко отключить»

> Этот файл — рабочая спецификация форка. В Merge Request в upstream он не включается.

## 1. Цель

Пациент без медицинского образования видит в OSCAR десятки цифр и сокращений (AHI, RERA, ODI,
95 %, FL, Glasgow…). Наведение мыши на цифру или термин даёт короткую расшифровку и ориентир;
панель справки — полное пояснение. Режим отключается одной галочкой.

Решения владельца: охват первого этапа — **цифры и термины** (меню и настройки — второй этап);
вид — **оба**: всплывающая подсказка и панель справки; устройство — **подход A**: словарь в C++
с обычным переводом Qt.

### Что уже есть
- ~180 подсказок Qt в меню/настройках (все переведены) — «что делает кнопка».
- `schema::Channel::description()` у ~250 каналов (переведены) — показываются в подсказках графиков
  «Дня» (`gGraphView.cpp:2126/2137` через `channelInfo()`, `daily.cpp:94`) и в `title=` боковой
  панели «Дня» (`daily.cpp:1781, 2040–2069`).
- «Статистика» — `MyTextBrowser` (QTextBrowser), строки без подсказок.
- Графики рисуют подсказки сами (`gToolTip`, `gGraph::ToolTip()`); `AppSetting->graphTooltips()`
  включает лишь часть.
- Шаблон настройки программы: `AppWideSetting` (`SleepLib/appsettings.h`).

## 2. Словарь (`oscar/glossary.{h,cpp}`)

```
struct GlossaryEntry {
    QString key;          // "ahi", "leak", "fl_time", "glasgow", …
    QString term;         // "AHI"
    QString expansion;    // "индекс апноэ-гипопноэ"
    QString summary;      // 1–2 фразы: что это (≤ 300 знаков)
    QString details;      // как считается, как понимать, частые ошибки толкования
    QString norm;         // норма или ориентир; пусто — нет
    bool experimental;    // мера анализа OSCAR, не медицинская норма
    QStringList seeAlso;  // ключи связанных статей
};
namespace Glossary {
    const GlossaryEntry *find(const QString &key);
    QList<GlossaryEntry> all();
    QString tooltip(const QString &key);   // короткий HTML: <b>термин</b> — расшифровка; summary; норма
    QString panel(const QString &key);     // полный HTML для панели
    QString keyForChannel(ChannelID code); // статья канала; пусто — нет
    QString channelTooltip(ChannelID code);// статья или, если её нет, нынешнее описание канала
    QList<QString> search(const QString &text);  // по термину/расшифровке/тексту; «ё» = «е»
}
```
Тексты — `QT_TRANSLATE_NOOP("Glossary", …)` в одной таблице; переводятся `QCoreApplication::translate`
при выдаче. Норма показывается с пометкой «ориентир», если она не общепринятая; у
экспериментальных мер — оговорка «экспериментальная мера анализа OSCAR, не медицинская норма».

### Статьи первого этапа (≈75)
- **Терапия:** использование (часы), соблюдение (4 ч), AHI, RDI, OAI, CAI, HI, UAI, RERA, FL
  (аппарат), CSR / периодическое дыхание, LL (большая утечка), утечка (средняя, 95 %, красная
  линия), давление (95 %, медиана, на максимуме), EPAP / IPAP / PS, режим (CPAP/APAP/BiPAP),
  EPR / softPAP / IPR, рамп, мин/макс давление APAP, частота дыхания, дыхательный объём, минутная
  вентиляция, Ti/Te, I:E, храп, флаги событий (тип событий на графике), сеанс, «маска снята».
- **Статистика:** медиана, 95-й перцентиль, максимум, взвешенное среднее, «ночей с данными»,
  «% соблюдения», период (последняя ночь / неделя / месяц / …).
- **Оксиметрия:** SpO2, SpO2 ниже 90 % / 88 % (T90), ODI 3 % / 4 %, надир SpO2, пульс, рост
  пульса, перфузия, плетизмограмма.
- **Анализ OSCAR (экспериментальные):** второе мнение, AHI анализа, правила гипопноэ (AASM 3 %,
  CMS 4 %, только поток, авто), согласие с аппаратом, гипоксическая нагрузка, зоны проблем
  оксиметрии, необъяснённые десатурации, реакция пульса на события, неоценимое время, FL score,
  время ограничения потока (минуты, % времени, самый длинный участок, % вдохов), Glasgow Index
  (оригинал, адаптированный) и 9 его признаков.
- **Сравнение настроек и сводка для врача:** столбцы сравнения, «лучшее значение», «мало ночей».

## 3. Механизм (`oscar/helptips.{h,cpp}`)

`HelpTips` — один объект на программу (`HelpTips::instance()`).
- `bool enabled()` / `setEnabled(bool)` — новая настройка программы `STR_AS_HoverHelp`
  («HoverHelp», по умолчанию `true`) в `AppWideSetting`; меню «Вид → Пояснения при наведении»
  (галочка). Выключение убирает только новые пояснения; старые подсказки Qt остаются.
- сигнал `hovered(const QString &key)` — для панели.
- **Виджеты:** `HelpTips::attach(QWidget*, key)` ставит свойство `helpKey`; фильтр событий на
  `QApplication` на `QEvent::ToolTip` показывает `QToolTip::showText(Glossary::tooltip(key))`, на
  `QEvent::Enter` шлёт `hovered`. Без ключа или при выключенной галочке — обычное поведение.
- **HTML-страницы** (стартовая страница, боковая панель «Дня», «Статистика», окно сводки для
  врача): `HelpTips::term(text, key)` оборачивает термин в `<a href='help:key' title='…'
  style='color:inherit;text-decoration:none'>`; при выключенной галочке возвращает текст как есть.
  Обработчики `highlighted(QUrl)` этих QTextBrowser шлют `hovered`, `anchorClicked` на `help:`
  открывает панель на статье (не переходит по ссылке). Существующие ссылки страниц не меняются.
- **Графики** («День», «Сводка»): при наведении на заголовок / подпись оси `gGraphView` берёт
  текст подсказки из `Glossary::channelTooltip()` (или по ключу графика анализа), если пояснения
  включены, и шлёт `hovered`; иначе — нынешнее поведение.

## 4. Панель справки (`oscar/helppanel.{h,cpp}`)

`QDockWidget` главного окна, справа, ширина ~300 px; перетаскивается, отстыковывается,
закрывается; «Вид → Панель справки». Видимость, место и размер — в настройках окна (как прочие
панели). Содержимое (QTextBrowser):
- статья последнего наведённого термина: термин и расшифровка крупно; «Что это», «Как понимать»,
  «Норма / ориентир», «Оговорка»; «См. также» — ссылки на статьи;
- статья не исчезает при уводе мыши; меняется при наведении на другой термин;
- без статьи — «Наведите мышь на цифру или термин» и поле поиска по словарю (результаты списком,
  клик — статья).

## 5. Где подключается (первый этап)
- **Стартовая страница** (`nightsummary.cpp`): плитки (заголовок, строки под цифрой), полоски
  «Использование» и «AHI: медиана», строка «Есть на что обратить внимание».
- **«День», боковая панель** (`daily.cpp`, `analysispanel.cpp`): строки событий и статистики ночи
  (по каналам), блок «Анализ (второе мнение)» (все строки, правила, согласие, гипоксическая
  нагрузка, зоны, 9 признаков Glasgow), настройки аппарата (режим, EPR/softPAP, давления).
- **«День», графики:** заголовок и подпись оси каждого графика.
- **«Сводка»:** заголовки графиков по ночам, включая графики анализа.
- **«Статистика»** (`statistics.cpp`): первая колонка каждой строки; столбцы сравнения настроек.
- **Окно сводки для врача:** термины плиток и таблицы (в PDF — нет).

Не в первом этапе: меню, кнопки, настройки, окна импорта и оксиметрии.

## 6. Тесты и проверка
- **Словарь:** у каждой статьи есть term, summary, details; ключи уникальны; ссылки «См. также»
  существуют; summary ≤ 300 знаков; `search` находит по части слова и «ё/е».
- **Полнота:** у каждой строки «Статистики» (ключи строк и каналы), каждого графика «Дня» и
  «Сводки» и каждой плитки стартовой страницы есть статья или описание канала — тест падает,
  если добавят строку без пояснения.
- **Механизм:** виджет с ключом показывает подсказку и шлёт `hovered`; при выключенной галочке —
  нет; `term()` даёт ссылку `help:` при включённой и голый текст при выключенной; `help:` в
  `anchorClicked` открывает панель, не уходя со страницы.
- **Панель:** показывает статью по `hovered`, не очищается при уводе, «См. также» и поиск
  открывают статьи.
- **Перевод:** все новые строки на русском; 0 незаконченных, `validate_ts.py` = 0.
- **В приложении** (только `--datadir …/OSCAR20_Data_dev`): наведение на плитку, строку
  «Статистики», график «Дня», строку панели анализа; выключение галочкой; панель и поиск;
  снимки — владельцу.
