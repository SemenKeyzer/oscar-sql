## 1. Цель

Врач смотрит график потока ночи, видит ошибку аппарата и исправляет разметку: добавляет пропущенное
событие, убирает ложное, меняет тип, исключает шумные участки. OSCAR пересчитывает AHI с учётом
правок — везде, как при отключении сеанса. Исходные события аппарата не меняются, разметку можно
отменить.

Решения владельца: исправленный AHI идёт **везде** («День», «Статистика», «Сводка», стартовая
страница, PDF) с пометкой «исправлено вручную»; действия — **все четыре** (добавить, убрать, сменить
тип, исключить участок), исключённых участков за ночь может быть несколько; устройство —
**подход A**: правки отдельным слоем поверх данных аппарата.

## 2. Данные

### 2.1 Таблица `manual_scoring` (схема 21 → 22)
Одна строка на правку:

| Поле | Что |
|---|---|
| `id` | ключ |
| `session_id` | сеанс (внешний ключ, удаление сеанса удаляет правки) |
| `kind` | `add` / `remove` / `retype` / `exclude` |
| `channel` | код канала: тип добавленного события; для `remove`/`retype` — исходный тип |
| `new_channel` | для `retype` — новый тип; иначе пусто |
| `start_ms`, `end_ms` | для `add` и `exclude` — участок; для `remove`/`retype` — `end_ms` = время события аппарата (время отметки), `start_ms` = `end_ms` − длительность |
| `note` | необязательная заметка («артефакт», «бодрствование») |
| `created_at` | время правки |

Миграция только добавляет пустую таблицу; данные аппарата не трогаются. Как и прочие обновления
схемы, OSCAR спрашивает подтверждение при первом открытии базы.

### 2.2 Какие события
Каналы AHI: обструктивное апноэ (`CPAP_Obstructive`, OA), центральное (`CPAP_ClearAirway`, CA),
неклассифицированное апноэ (`CPAP_Apnea`, A), гипопноэ (`CPAP_Hypopnea`, H). Смена типа — между
ними. RERA, храп, ограничение потока и прочие отметки не размечаются.

## 3. Расчёт

- Событие аппарата отмечено моментом окончания (время в `EventList`, длительность — значение).
  Добавленное событие считается по `end_ms`.
- Итоговые события сеанса = события аппарата **минус** убранные (совпадение канала и времени в
  пределах ±1 с) **со сменённым типом** у исправленных **плюс** добавленные; затем отбрасываются
  события, чей момент окончания попал в исключённый участок.
- Знаменатель AHI = время работы аппарата (как сейчас, `hours(MT_CPAP)`) **минус** суммарная длина
  исключённых участков, пересечённых с сеансами (участки объединяются, перекрытия не вычитаются
  дважды, части вне сеанса отбрасываются).
- Пересчёт в одном месте: класс `ManualScoring` (новый, `SleepLib/manual_scoring.{h,cpp}`) даёт
  поправленные счётчики по каналам AHI и исключённое время для дня; `Day::count` для каналов AHI и
  `Day::calcAHI/calcOAHI/calcCAHI/calcRDI` (знаменатель) берут их. Через `Day` правки попадают во
  все страницы и PDF.
- Не меняются: использование, соблюдение режима, давление, утечка, прочие каналы, собственный анализ
  OSCAR (второе мнение, Glasgow Index) — он остаётся независимой оценкой.
- Правка `remove`/`retype`, чьё событие аппарата не найдено (данные перестроили), не учитывается и
  показывается в списке правок как «событие не найдено».
- **Клинический режим:** разметка разрешена (это работа врача), ночь помечается.

## 4. Интерфейс (страница «День»)

### 4.1 Режим разметки
- Кнопка-переключатель **«Разметка»** на нижней панели «Дня» рядом с «Выровнять».
- В режиме: протягивание мыши по графику потока (`FlowRate`) выделяет участок вместо увеличения;
  вверху графиков полоса «Режим разметки: выделите участок или щёлкните правой кнопкой по событию ·
  Esc — выход». Вне режима поведение графиков не меняется.

### 4.2 Меню
- **После выделения участка:** «Обструктивное апноэ · Центральное апноэ · Апноэ
  (неклассифицированное) · Гипопноэ · Исключить участок (шум / бодрствование)»; в заголовке меню —
  длительность участка; при длительности < 10 с у пунктов событий предупреждение «короче 10 с»
  (отметить всё равно можно).
- **Правая кнопка по отметке события** (график событий или поток): «Убрать событие (не считать)»,
  «Сменить тип → OA / CA / A / H»; у исправленного — «Вернуть как было»; правая кнопка по
  исключённому участку — «Отменить исключение».

### 4.3 Как видно на графиках
- добавленные события — цвет типа, пунктирная рамка, подпись «ручн.»;
- убранные — бледные и перечёркнутые;
- со сменённым типом — новый цвет и метка «было CA» (исходный тип);
- исключённые участки — серая штриховка через все графики ночи.

### 4.4 Боковая панель «Дня»
- строка AHI: «AHI 4.2 (по аппарату 5.1) · исправлено вручную» — когда есть правки;
- блок **«Ручная разметка»**: «добавлено 3, убрано 2, сменён тип 1, исключено 14 мин (2 участка)»;
  список правок со временем (щелчок — переход к правке на графике, крестик — отменить правку);
  кнопка «Отменить всю разметку ночи» (с подтверждением).

### 4.5 Остальные страницы
«Статистика», «Сводка», стартовая страница, PDF — пометка «исправлено вручную» у ночи / периода с
правками; в PDF дополнительно строка «AHI по аппарату: X».

### 4.6 Пояснения при наведении
Кнопка, пункты меню и блок получают статьи словаря; тест полноты пояснений проходит.

## 5. Тесты и проверка
- **Расчёт** (синтетическая ночь): добавление ↑ счётчик и AHI; удаление ↓; смена типа переносит
  между счётчиками, общий AHI тот же; событие с концом в исключённом участке не считается, время
  участка вычитается из знаменателя; несколько участков, перекрывающиеся объединяются, выход за сеанс
  обрезается; использование, соблюдение, давление не меняются; правка на несуществующее событие
  игнорируется и помечается; отмена правки и «отменить всё» возвращают цифры аппарата.
- **Хранение:** сохранение и чтение из базы; правки переживают повторное открытие профиля,
  перестройку и повторный импорт; удаление сеанса удаляет его правки; миграция 21 → 22.
- **Где видно:** AHI с правками одинаков в «Дне», «Статистике», «Сводке», стартовой странице, PDF;
  «AHI по аппарату» — в боковой панели и PDF.
- **Интерфейс:** в режиме выделение на потоке открывает меню, а не увеличивает; вне режима — как
  раньше; меню правой кнопки содержит нужные пункты; предупреждение < 10 с; Esc выходит из режима.
- **Перевод и пояснения:** все строки на русском, `validate_ts.py` = 0; тест полноты пояснений.
- **В приложении** (только `--datadir …/OSCAR20_Data_dev`, фоновые `app_*`): включить режим,
  панель и блок разметки на месте; выделение мышью проверяет владелец.
