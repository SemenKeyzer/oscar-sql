## 1. Цель

Меньше «шума» в левой панели «Дня»: вкладки помещаются и видны сразу; ручная разметка живёт в своей
вкладке; рамка AHI ясно разделяет цифру аппарата, анализа OSCAR и ручной разметки.

Решения владельца: вкладка «Ручной анализ» видна **всегда**; рамка AHI — **вариант A** (аппарат
крупно, анализ и разметка ниже).

## 2. Вкладки кнопками

- Полоса вкладок левой панели (`ui->tabWidget`) скрыта; над её страницами — кнопки в два ряда:
  - ряд 1: **Подробности · События · Анализ OSCAR · Ручной анализ**;
  - ряд 2: **Примечания · Закладки · Поиск**.
- Кнопки-переключатели (одна выбрана), вид — общий стиль наборов «Сводки»
  (`OverviewPresets::buttonStyle`): выбранная подсвечена синим.
- «Анализ OSCAR» видна только при `analysis::analysisShown()`; если анализ прячут, когда выбрана
  она, выбираются «Подробности».
- Выбранная вкладка запоминается и восстанавливается, как сейчас.
- Перетаскивание вкладок местами пропадает; порядок фиксирован.
- Каждая кнопка — пояснение при наведении (как у прежних вкладок).

## 3. Рамка AHI («Подробности»), вариант A

- Крупно: **AHI по аппарату** (`Day::deviceAHI()`; для RDI — так же, как сейчас подпись).
- Ниже, в одной строке через вертикальную черту: «анализ OSCAR — X» и «ручная разметка — Y»;
  прочерк «—», где значения нет; при выключенном анализе часть «анализ OSCAR» не выводится.
- Цвет рамки — по итоговому (исправленному) AHI, как сейчас.
- Прежняя строка «по аппарату X · исправлено вручную» и отдельная строка «анализ OSCAR: X» уходят —
  их заменяет новая разметка рамки.

## 4. Вкладка «Ручной анализ»

- Сверху: **AHI после ручной разметки** «Y, по аппарату X» (если правок нет — только подсказка).
- Ниже — весь нынешний блок «Ручная разметка» из «Подробностей»: итоги (добавлено, убрано, сменён
  тип, границы изменены, исключено), список правок (щелчок — переход, крестик — отмена), «Отменить
  всю разметку ночи».
- Без правок: «Ручной разметки этой ночи нет — включите «Разметку» внизу, чтобы исправить события.»
- Позже здесь же — ручное ограничение потока (п. 18 врача, отдельная задача).
- Блок «Ручная разметка» из «Подробностей» удаляется.
- Ссылки списка обрабатываются как сейчас (`Daily::Link_clicked`, `scoring=…`).

## 5. Тесты

- Кнопки: порядок и тексты; одна выбранная; выбор кнопки меняет страницу; «Анализ OSCAR» скрыта при
  выключенном анализе и при скрытии переключает на «Подробности».
- Рамка AHI: крупно аппарат; «анализ OSCAR» и «ручная разметка» с числами и прочерками; без части
  анализа при выключенном анализе.
- «Ручной анализ»: AHI после разметки, список правок; подсказка без правок.
- «Подробности» без блока «Ручная разметка».
- Перевод: всё на русском, `validate_ts.py` = 0; тест полноты пояснений.
- В приложении: только `--datadir …/OSCAR20_Data_dev`, запуск через `open -n`; проверяет владелец.
