## 1. Цель

Цифры аппарата, анализа OSCAR и ручной разметки не должны сливаться. В «Дне» они идут отдельными
группами, а всё, что посчитал анализ OSCAR, на любой странице помечено одинаково: меткой «анализ» и
фиолетовой полосой.

Решения владельца:
- одна часть работы: «День» и остальные страницы вместе;
- строки аппарата в таблице индексов показывают **чистые цифры аппарата** (без ручных правок);
  исправленные цифры по типам событий — на вкладке «Ручной анализ»;
- дерево «События» — **плоский список с заголовками-разделителями**;
- пометка — **вариант A**: слово «анализ» в скруглённой рамке и фиолетовая полоса слева у строки;
- в «Статистике» раздел анализа остаётся **отдельным** (не строками-парами под строками аппарата,
  как предлагалось в прежней задаче 4): так требует главное пожелание врача — разделять.

## 2. Модуль пометки `analysismark`

Один модуль, которым пользуются все страницы; никто не рисует пометку сам.

- Цвета: полоса `#7F77DD`; фон метки `#EEEDFE`; текст метки `#3C3489`.
- `pill()` — HTML-метка: слово «анализ» (источник `tr("analysis")`) в скруглённой рамке; при наведении
  пояснение «Второе мнение OSCAR, экспериментально» (источник
  `tr("OSCAR's second opinion, experimental")`).
- `rowStyle()` — стиль ячейки строки анализа в HTML-таблице: фиолетовая полоса слева.
- `printPill()` — вариант для печати и PDF: слово в рамке, читается и в чёрно-белой печати.
- Для дерева событий — оформление заголовка-разделителя (полоса и метка).

## 3. «День»

### 3.1 Таблица индексов («Подробности»), п. 8

- Сначала строки аппарата. Значение — **по аппарату**: число событий аппарата в час, без учёта ручных
  правок (сейчас строка уменьшается на убранные вручную события).
- Затем строка-разделитель «Анализ OSCAR» с меткой; под ней строки каналов анализа с полосой.
  Названия строк анализа — без «(анализ)»: принадлежность показывает разделитель и полоса.
- Анализ выключен (`analysis::analysisShown()` ложно) или каналов анализа нет — ни разделителя, ни строк.
- Прочие строки (Apple, температура запястья и т. п.) — в группе аппарата, как сейчас.

### 3.2 Вкладка «Ручной анализ»

- Под строкой «AHI после ручной разметки» — таблица «тип события: по аппарату → после разметки»,
  только для типов событий, у которых есть правки (добавлены, убраны, сменён тип).
- Без правок — подсказка, как сейчас.

### 3.3 Дерево «События», п. 12

Порядок верхних строк:
1. типы событий аппарата; «Начало сеанса», «Конец сеанса»; «Все» (если включено объединение);
2. заголовок «Анализ OSCAR» с меткой; под ним типы событий анализа (только при включённом анализе);
3. заголовок «Ручная разметка»; под ним список правок, как сейчас (щелчок — переход, правая кнопка —
   отмена).

- Заголовки нельзя выбрать и нажать; щелчок по ним ничего не делает.
- Группа без строк не показывается вместе со своим заголовком.
- События аппарата в дереве — как записал аппарат (убранные вручную тоже видны: это данные аппарата).
- Узел «Все» собирает только события аппарата.

### 3.4 Остальное

- Рамка AHI: часть «анализ OSCAR — X» получает метку.
- Раздел «Анализ (второе мнение)»: метка в заголовке.
- Графики анализа в «Дне» подписаны единообразно: «… · анализ».

## 4. Другие страницы

### 4.1 «Статистика»

- Раздел «Анализ (второе мнение)» остаётся отдельным после строк аппарата.
- Его заголовок и каждая строка — с меткой и полосой; «AHI (анализ)» становится «AHI» с меткой.
- То же при печати и в PDF «Статистики» (вариант для печати).

### 4.2 «Начало»

- Плитка AHI: заметка «анализ OSCAR: X» — с меткой.
- Плитка SpO2: ODI 3 % (его считает анализ OSCAR) — с меткой.
- Предупреждение «анализ OSCAR насчитал AHI больше, чем аппарат» — с меткой.

### 4.3 PDF для врача

- Строка «Анализ OSCAR: … ограничение потока … Glasgow …» и ODI — с меткой (вариант для печати).
- Строка о ночах без анализа — как есть.

### 4.4 «Сводка»

- Все графики анализа подписаны «… · анализ» (источник `tr("%1 · analysis")`): AHI, ODI 3 % / 4 %,
  время SpO2 в диапазонах, зоны проблем оксиметрии, гипоксическая нагрузка, ограничение потока
  (% и минуты), Glasgow, индекс подъёмов пульса.
- Подсказка графика AHI: «AHI · анализ» вместо «AHI (анализ)».

### 4.5 «Сравнение настроек»

- Заголовки колонок анализа (AHI анализа, ограничение потока, Glasgow, ODI 3 %, SpO2 < 90 %) — с меткой.

## 5. Тесты

- Модуль: HTML метки (слово, цвета, пояснение), стиль строки, вариант для печати.
- «День», таблица: порядок «аппарат → разделитель → анализ»; при ручных правках строка аппарата
  показывает число аппарата; без анализа (переключатель выключен) — нет разделителя и строк анализа.
- «День», дерево: порядок групп; заголовки не выбираются; пустые группы со своими заголовками скрыты;
  при выключенном анализе — нет группы анализа.
- «Ручной анализ»: таблица «по аппарату → после разметки» только для типов с правками.
- Другие страницы: метка есть в HTML «Статистики», «Начала», PDF для врача, «Сравнения настроек»;
  у графиков «Сводки» подпись «· анализ».
- Перевод: всё на русском, `validate_ts.py` = 0; тест полноты пояснений проходит.
- В приложении: только `--datadir …/OSCAR20_Data_dev`, запуск через `open -n`; проверяет владелец.

- Ручное ограничение потока (п. 18), имена в меню разметки, прочие замечания врача.
