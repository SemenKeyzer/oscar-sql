## 1. Цель

Скачивать ночные записи с пульсоксиметра Wellue / Viatom **O2Ring** прямо в OSCAR по Bluetooth, без
приложения ViHealth и ручного переноса файлов. Кнопка — в мастере импорта оксиметрии, рядом с Contec.

Решения владельца: скачивать **только новые** записи (уже импортированные можно отметить вручную);
**отдельный набор классов по образцу Contec**, страница Contec не меняется; проверка на живом кольце —
у владельца.

## 2. Протокол (версия V1, без шифрования)

- BLE GATT. Сервис `14839ac4-7d7e-415c-9a42-167340cf2339`; запись
  `8b00ace7-eb0b-49b0-bbe9-9aee0a26e1a3` (без ответа); уведомления
  `0734594a-a8e7-4b1a-a6b1-cd5243059a57`. Имя в рекламе «O2Ring <6 цифр>». Одно подключение за
  раз (приложение на телефоне должно быть закрыто). Без сопряжения.
- Запрос: `AA | cmd | ~cmd | seq lo | seq hi | len lo | len hi | данные | crc8`.
- Ответ: `55 | status | ~status | seq (2, LE) | len (2, LE) | данные | crc8`; `status 00` — успех;
  проверка `байт1 == ~байт2`.
- CRC-8: полином 0x07, начальное 0, без отражений и xorout, по всем байтам, кроме последнего.
  Контрольный пример: `AA 14 EB 00 00 00 00` → `C6`.
- Ответ приходит частями: копить буфер, искать `55` с `байт1 == ~байт2`, ждать `len + 8` байт,
  проверять CRC; `len` больше 8192 — ложное начало.
- Команды:
  - `0x14` сведения — JSON (ASCII): `SN`, `Model`, `SoftwareVer`, `CurTIME` («yyyy-MM-dd,HH:mm:ss»),
    `CurBAT` («65%»), `FileList` (имена «yyyyMMddHHmmss» через запятую, с запятой в конце) и др.;
  - `0x16` установка часов — JSON `{"SetTIME":"yyyy-MM-dd,HH:mm:ss"}` (местное время) → только статус;
  - `0x03` начало чтения файла — имя (ASCII) + `00` → размер `uint32 LE` (больше 2 000 000 или 0 —
    ошибка);
  - `0x04` данные файла — без данных, `seq` = номер куска 0, 1, 2…; до получения ровно заявленного
    размера;
  - `0x05` конец чтения — **отправлять всегда**, в том числе после ошибки.
- Стирания в V1 нет (`0x18` — сброс к заводским, **не используется**). Кольцо само затирает старые
  записи.
- Файл кольца — ровно формат, который разбирает `ViatomLoader` (версия 3): сохраняется как есть.

## 3. Мастер оксиметрии

- На странице выбора способа — кнопка **«O2Ring (Bluetooth)»** (рядом с кнопкой Contec), только в
  сборке с Bluetooth (`HAVE_BLUETOOTH`).
- Страница O2Ring:
  1. поиск колец «O2Ring …»; подсказка: «Закройте приложение ViHealth на телефоне — кольцо держит
     одно подключение; наденьте кольцо, чтобы оно проснулось»;
  2. подключение; сведения: серийный номер, заряд, время кольца и время компьютера;
  3. галочка **«Установить часы кольца»** (по умолчанию включена, выбор запоминается в настройках
     приложения);
  4. список записей кольца: дата и время начала, отметка «уже в OSCAR» / «новая»; новые отмечены,
     уже импортированные — нет (можно отметить вручную);
  5. «Скачать» — прогресс по каждой записи, затем импорт, итог («импортировано N, пропущено M»);
  6. «Готово» закрывает мастер и обновляет «День».
- Страница времени начала не нужна: время записи берётся из файла кольца.

## 4. Хранение и импорт

- Скачанная запись сохраняется как есть в резервную папку профиля
  `<папка профиля>/Backup/O2Ring_<SN>/<yyyyMMddHHmmss>` (запись во временный файл и переименование;
  повторное скачивание заменяет файл).
- Импорт файла — `ViatomLoader` (он берёт серийный номер из имени папки).
- «Уже в OSCAR»: у прибора Viatom с этим серийным номером есть сеанс с номером, который
  `ViatomLoader` дал бы этой записи (время начала из имени файла).

## 5. Ошибки

- Нет Bluetooth / нет разрешения ОС — понятное сообщение (на macOS нужен ключ
  `NSBluetoothAlwaysUsageDescription`, он уже есть).
- Кольцо не найдено — подсказка из п. 3.1, «Повторить».
- Обрыв, потерянный ответ: ожидание ответа 5 с, до 4 попыток на команду; недокачанный файл не
  сохраняется (размер должен точно совпасть); уже скачанные записи остаются; `0x05` отправляется.
- Запоздалый повтор ответа не сдвигает куски (сверка `seq` и итогового размера).
- Зашифрованное кольцо (V1 с шифрованием) или O2Ring S / протокол V2 — «Это кольцо пока не
  поддерживается».

## 6. Устройство

Новые файлы рядом с Contec (`SleepLib/loader_plugins/`), по тем же слоям:
- `o2ring_protocol.{h,cpp}` — кадры, CRC-8, сборщик ответов из уведомлений, разбор сведений и
  списка файлов, JSON установки часов (чистые функции, без Qt Bluetooth);
- `o2ring_link.{h,cpp}` — абстрактная связь и реализация на QtBluetooth (поиск, подключение,
  уведомления, запись);
- `o2ring_downloader.{h,cpp}` — порядок команд (сведения → часы → для каждой выбранной записи
  начало / куски / конец), ожидания и повторы;
- `o2ring_import.{h,cpp}` — сохранение в резервную папку, импорт через `ViatomLoader`, «уже в
  OSCAR»;
- `o2ringpage.{h,cpp}` — страница мастера.

## 7. Тесты

- Протокол: контрольный пример CRC; кадр запроса; ответ, разбитый на несколько уведомлений;
  ложное начало; неверная CRC; разбор сведений и `FileList`; JSON часов.
- Загрузчик на поддельном кольце: обычное скачивание двух записей; потерянный ответ и повтор;
  запоздалый повтор ответа; обрыв посреди файла (файл не сохранён, `0x05` отправлен); размер не
  совпал.
- Импорт: синтетический файл (как `make_file()`) сохраняется в `Backup/O2Ring_<SN>/` и
  разбирается в сеанс; та же запись затем отмечается «уже в OSCAR».
- Пояснения при наведении (тест полноты) и перевод (`validate_ts.py` = 0).
- На устройстве — владелец (только `--datadir …/OSCAR20_Data_dev`, запуск через `open -n`).

## 8. Вне рамок

- Зашифрованные кольца, O2Ring S / протокол V2, другие модели (Checkme O2, SleepU и т. п.) — не
  проверены.
- Запись в реальном времени, стирание, настройки кольца (вибрация, пороги).
- Личные записи владельца в репозиторий не попадают; тесты — только на синтетических файлах.
