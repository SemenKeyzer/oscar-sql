# Ручное ограничение потока — дизайн

- Дата: 2026-10-16
- Ветка: `master` форка `SemenKeyzer/oscar-sql`
- Статус: дизайн согласован с владельцем в чате; ждёт просмотра спецификации
- Источник: замечания врача (видео 2026-10-09), п. 18 файла `Oscar_Project/Замечания врача 2026-10-09.md`
  («главное новое пожелание»).

> Этот файл — рабочая спецификация форка. В Merge Request в upstream он не включается.

## 1. Цель

Врач отмечает на графике потока участки (обычно 1–3 минуты) с ограничением потока; слева видно,
какая доля ночи и сколько минут с ограничением потока по его ручной разметке.

Решение владельца: **только процент и минуты по ручной разметке**. Флаги ограничения потока аппарата
(FL) и анализа OSCAR остаются как есть и не правятся.

## 2. Разметка

- В меню выделения (режим «Разметка») после типов событий — пункт **«Ограничение потока»**, буква
  **F** (в русской раскладке — та же клавиша, «А»); перед «Артефактом».
- Отмеченный участок рисуется на графике потока полупрозрачной полосой своего цвета (не серой, как
  артефакт) с подписью «ОП м:сс» (длительность), видна и вне режима разметки.
- Края полосы тянутся мышью, как у артефакта и рамок событий.
- Правая кнопка по полосе — «Отменить» (U).
- Повтор типа работает: выбрали «Ограничение потока» — следующие выделения сразу становятся им.
- Накладывающиеся и стыкующиеся участки считаются один раз (объединение).

## 3. Подсчёт

- Минуты: длина объединения участков ограничения потока, без времени в участках «Артефакт».
- Процент: от часов, по которым считается AHI (`Day::ahiHours()`: часы CPAP без артефактов).
- Не влияет на AHI, индексы событий и флаги аппарата/анализа.

## 4. Где видно

- Вкладка «Ручной анализ»: строка «Ограничение потока (ручная разметка): X % ночи, Y мин»
  (только если есть участки).
- Список правок («Ручной анализ», дерево «События» → «Ручная разметка»): «ограничение потока
  м:сс» — щелчок переход, крестик/правая кнопка отмена.
- Полосы на графике потока (п. 2).

## 5. Хранение

- Новый вид правки «отмеченный участок» (`Kind::Mark`, в базе текст `mark`) с каналом нового
  вычисляемого канала ручного ограничения потока; в той же таблице `manual_scoring`. Новых таблиц
  нет, версия схемы не меняется.
- Новый канал — тип SPAN, «Ограничение потока (ручная разметка)», в индексы AHI не входит.

## 6. Тесты

- Сумма и объединение участков; вычитание артефактов; процент от часов AHI.
- Пункт меню, буква F (латиница и кириллица), повтор типа.
- Отмена; перетаскивание краёв участка.
- Строка на «Ручном анализе»; строка в списке правок.
- Сохранение и чтение правки `mark` из базы.
- Перевод (`validate_ts.py` = 0), тест полноты пояснений.
- В приложении: только `--datadir …/OSCAR20_Data_dev`, запуск через `open -n`; проверяет владелец.
